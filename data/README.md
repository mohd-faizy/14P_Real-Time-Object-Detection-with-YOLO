# Data Directory

This directory contains the essential media assets and label mappings used for YOLO26 object detection.

## Directory Contents

| Path | Description |
| :--- | :--- |
| `images/` | Sample images (`dog.jpg`, `person.jpg`, `traffic.jpg`, `traffic.png`) for static image inference. |
| `videos/` | Sample street and driving videos (`Chicago_360p.mp4`, `Driving-Chinatown-SF.mp4`, `market.mp4`) for real-time video detection. |
| `coco.names` | Complete reference list of 80 Microsoft COCO class labels (e.g., `person`, `bicycle`, `car`, `dog`, etc.). |
